This project focuses on developing the public-facing StechGrow website based on the provided Figma designs. It includes product information, company details, pricing plans, contact information and other supporting sections.

## Tech Stack

- **React** — Frontend UI development
- **Vite** — Development server and build tool
- **Tailwind CSS** — Styling and responsive layouts
- **React Router** — Navigation between pages

## Pages

- Home
- Solution
- Platform
- About
- Pricing
- Contact
- FAQ sections

## Getting Started

### 1. Clone the repository

```bash
git clone <repository-url>
cd stechgrow-website
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the website.
